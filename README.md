## Controls
WASD / arrow keys move; Space attacks; E interacts with the Root Shrine; Escape pauses. Mobile controls appear below the game.

## Keepers
Morrow (100 HP, 92 reach, 16 damage); Brik (145 HP, 62 reach, 30 damage); Vesper (78 HP, 124 reach, 12 damage); Moss (112 HP, 88 reach, 19 damage). Their reach values differ intentionally.

## Current features
Responsive lobby, four keeper selection, three chapter story descriptions, playable canvas arena, crystal pickups, chasing enemies, health, timer, restart/continue, local chat demo, voice-chat placeholder, and concept art.
